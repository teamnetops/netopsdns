How It Works

Simple setup.
Instant savings.

No complex infrastructure changes. Just one MikroTik rule — we handle everything else.

1

User Requests TikTok

Your PPPoE user opens TikTok. Their device sends a DNS query for example: mon-sg.tiktokv.com — normally this goes to Akamai (IIG).

2

MikroTik Redirects DNS

Your router's dst-nat rule silently redirects all DNS queries to our NetOpsDNS server over BDIX — the user never notices.

3

BOOST Steering Activates

Our DNS returns the Baishan CDN IP (154.85.74.x) instead of Akamai. TikTok's app triggers its built-in fallback mechanism.

4

Video Streams via BDIX

TikTok video data flows from Baishan CDN through BDIX — zero IIG usage. Every other website resolves normally without any impact.

Real traffic graph — CDN traffic handled over BDIX. IIG consumption drops to near zero.

Features

TikTok CDN Steering

BOOST-based DNS policy redirects TikTok traffic to Baishan CDN via BDIX. IIG usage for TikTok drops to zero — proven and running in production.

⚡

Auto Failover

Baishan nodes are checked every minute. If a node goes down, our system automatically switches to the healthy node — no manual action needed.

🔒

ACL-Based Access Control

Only your authorized IP prefixes can use the DNS service. Unauthorized IPs are refused instantly. Your service, your control.

📱

Telegram Real-Time Alerts

Get notified instantly when Baishan nodes go down, come back up, or any DNS issue occurs — even at 3am, you'll know before your users do.

🌐

Zero Website Downtime

Auto-fallback system detects broken domain delegations and forwards them to Google/Cloudflare automatically. No website is ever unreachable.

📊

Full DNS Recursion

We run a full recursive DNS resolver — not a forwarder. ~94% cache hit rate means fast responses for your users and minimal IIG for DNS itself.

🛡️

MikroTik Failsafe

A built-in script on your router monitors DNS health every 15 seconds. If our server is unreachable, it automatically re-enables normal DNS.

🔗

BDIX Connected

Our DNS server is BDIX-peered — all BD ISPs can reach us at 1 – 5ms latency with no IIG cost. Your users get fast DNS without leaving Bangladesh.

Web Management Panel
